# First public release notes — DRAFT

**STL Resin Cost Analyzer v1.0.0-beta.1** (Windows x64)

This is an initial public test release of a free, closed-source resin-printing estimator.

Highlights:
- Batch STL folder scanning with progress reporting.
- Slice-based volume, mass, resin cost and estimated print time.
- Interactive GPU OpenGL model viewer.
- Optional recursive scanning and local cache.
- Manual exchange-rate support for 20 currencies (USD default).
- CSV reporting and optional developer tips.

Known limitations:
- Estimates are not actual slicer outputs.
- Large, complex, or malformed meshes may take longer or give different results from CHITUBOX/Lychee.
- OpenGL-capable drivers/hardware are required for the viewport.
- Manual exchange rates do not update themselves.

**Do not publish a binary until the build, Windows smoke test, third-party license notices, and freeware terms are finalized.**
