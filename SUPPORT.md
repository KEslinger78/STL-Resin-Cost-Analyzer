# Help and support

Found a bug? [Open an issue](https://github.com/KEslinger78/STL-Resin-Cost-Analyzer/issues).

Please include the app version, Windows version, what you were doing, expected behavior, actual behavior and any error text. Describe sensitive models without uploading the files unless you own the rights to share them. If a preview fails for a large model, include its approximate file size and triangle count if known.

For security-sensitive issues, avoid placing exploit or private information in a public issue. Look for GitHub private vulnerability reporting if it is enabled; otherwise ask for a private contact channel without disclosing the vulnerability details publicly.
